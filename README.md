# AviUtl2 Font Auto Labeler

`aviutl2.ini` の `[Font.フォント名]` の `label` を自動設定し、`order` を読み順に整理するWebアプリ。

## 使い方

1. AviUtl2を終了し、`C:\ProgramData\aviutl2\aviutl2.ini` を読み込みます。
2. 分類結果を確認します。検索・分類での絞り込み・ラベルの手動変更ができます。
3. 更新した `aviutl2.ini` をダウンロードします。元のファイルをバックアップしてから置き換えてください。

## 分類とファイルの扱い

ラベルは `分類\頭文字` の2段です。例：`00Font` → `0-9\0`、`Arial` → `A-F\A`、`ゴシック` → `か行\こ`。既存の独自ラベルは保持します。

- 数字：`0-9`（全角数字も含む）。
- 英字：`A-F`、`G-N`、`O-T`、`U-Z`。
- 日本語：`あ行`、`か行`、`さ行`、`た行`、`な行`、`は行`、`ま行`、`や行`、`ら行`、`わ行`。「ん」は「わ行」に含めます。
- 記号・読みを判定できない漢字：`その他\その他`。
